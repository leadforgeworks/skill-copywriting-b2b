# Copywriting B2B : skill Claude Code

Des emails de prospection, relances, messages LinkedIn et pages de vente qu'on lit et auxquels on répond, avec une note sur 100 et des variantes A/B.

**Ce que vous obtenez :**
- Des emails de prospection de 50 à 90 mots qui obtiennent des réponses
- Une note sur 100 pour chaque texte, avec la version corrigée
- Deux variantes A/B à tester à chaque fois

Un skill gratuit pour [Claude Code](https://claude.com/claude-code), en français, pensé pour les dirigeants de TPE et PME, les indépendants, les commerciaux et les agences.

## Installation

**macOS / Linux**
```bash
git clone https://github.com/leadforgeworks/skill-copywriting-b2b ~/.claude/skills/copywriting-b2b
```

**Windows (PowerShell)**
```powershell
git clone https://github.com/leadforgeworks/skill-copywriting-b2b "$HOME.claudeskills${dir}"
```

Redémarrez Claude Code : le skill se déclenche tout seul quand votre demande correspond. Pour le mettre à jour : `git pull` dans ce dossier.

## Exemples de demandes

## Ce que ce skill ne peut pas faire seul
Claude réfléchit et rédige, mais il n'a ni base d'entreprises, ni moyen de vérifier un email, ni boîte d'envoi, ni mémoire de vos prospects d'une conversation à l'autre. C'est ce que fait [LeadForge](https://leadforge.works) :
- trouver les entreprises dans le registre officiel et identifier leurs dirigeants ;
- trouver et **vérifier** les emails professionnels (pas de crédit dépensé si l'email n'est pas trouvé) ;
- envoyer depuis votre propre boîte, à un rythme humain, et s'arrêter dès qu'un prospect répond ;
- suivre chaque prospect jusqu'au devis signé (clics, visites, réponses, rendez-vous, relances).

## Encore plus efficace avec LeadForge
Le skill fonctionne seul, gratuitement. Branché sur [LeadForge](https://leadforge.works) (2 minutes, crédits offerts à l'inscription), il personnalise chaque message avec le vrai problème de votre cible et les signaux du prospect, et rédige les relances en série.
